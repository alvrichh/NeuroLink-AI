# P300 spelling — secondary reference only

[Español](../../technical/p300-secondary-baseline.md)

P300 event-related potentials can support selecting characters from visual stimuli. This is **spelling by attention**, not decoding a sentence silently spoken to oneself. It is **not** NeuroLink AI's principal goal, but remains a useful non-invasive EEG baseline.

Reference: [BNCI2014-009 / MOABB](https://moabb.neurotechx.com/docs/generated/moabb.datasets.BNCI2014_009.html) (10 participants, 16 channels, 256 Hz). Check original license, session grouping and preprocessing.

Possible optional experiments: Target/NonTarget event classification, character reconstruction with genuine stimulus metadata, controls for leakage, character accuracy and rate. LLM corrections do not count as EEG-decoded language.

**Current main workstream:** [decoding prompted inner speech](phase-1-eeg-to-text.md) and [mental privacy](neural-privacy-firewall.md).
