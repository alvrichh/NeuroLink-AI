## What will count as a project-generated figure?

| Figure | Required original source | Status |
| --- | --- | --- |
| Real EEG waveform | Recorded licensed EEG; original dataset citation + preprocessing script | Not produced |
| ERP/P300 grand average | Actual public EEG plus MNE reproducible code and uncertainty | Not produced |
| Confusion matrix | Actual held-out predictions (no data leakage) | Not produced |
| HDL simulator waveform | Running testbench with documented simulator version | Not produced |
| KiCad circuit diagram | Authored and peer-reviewed EDA source | Not produced |
| Speller screenshot | A functioning interface with source mode and confirmation | Not produced |

## Why this distinction matters

A stock photograph, a nice-looking circuit diagram and a synthetic waveform can be useful explanatory aids. None proves the project has measured a brain signal. Each figure must identify whether it is **conceptual, mockup, simulated, measured or a licensed photograph**.
